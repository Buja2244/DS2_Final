# Predicción del Rendimiento Académico con Machine Learning

Proyecto de análisis de datos y Machine Learning orientado a la predicción del rendimiento académico de estudiantes utilizando técnicas de regresión y análisis exploratorio de datos.

## Objetivos
- Analizar factores que influyen en el rendimiento académico.
- Implementar modelos de Machine Learning.
- Comparar el desempeño de distintos modelos predictivos.
- Optimizar modelos mediante GridSearchCV.

## Tecnologías utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Modelos implementados
- Regresión Lineal
- Random Forest Regressor
